# Verhaltenskodex

Dieses Projekt soll ein respektvoller Ort für alle sein, die Fehler melden, Ideen einbringen oder Code beitragen. Er folgt dem Geist des [Contributor Covenant](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).

## Erwartet
- Sachlich, freundlich und respektvoll miteinander umgehen, auch bei Meinungsverschiedenheiten.
- Kritik an der Sache, nicht an der Person.
- Rücksicht darauf, dass das Projekt in der Freizeit gepflegt wird.

## Nicht akzeptabel
- Beleidigungen, Herabsetzung, Belästigung oder Diskriminierung jeder Art.
- Veröffentlichen privater Informationen anderer ohne deren Einwilligung (auch echte Rechnungsdaten).
- Spam und Werbung ohne Bezug zum Projekt.

## Durchsetzung
Die Maintainer können Beiträge entfernen, bearbeiten oder ablehnen und Personen vorübergehend oder dauerhaft ausschließen. Verstöße bitte vertraulich über die Meldefunktion von GitHub („Report content“) oder über das Profil [@ebolansk](https://github.com/ebolansk) melden.
